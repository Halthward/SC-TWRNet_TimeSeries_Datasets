# SC-TWRNet_TimeSeries_Datasets
Datasets, preprocessing code and source links for the paper "Efficient Multivariate Time Series Forecasting with SC-TWRNet: Combining Adaptive Multi-Resolution Wavelet and Parallelizable Decomposition" (submitted to Applied Sciences, MDPI)


# Acknowledgment
The datasets and data processing code used in this GitHub repository are derived entirely from the open-source project Time Series Library (TSLib) (repository address: https://github.com/thuml/Time-Series-Library).
TSLib is maintained by the Tsinghua University Machine Learning Group (THUML). It covers mainstream time series analysis tasks including long-term/short-term forecasting, imputation, anomaly detection, and classification, and provides standardized datasets, data processing logic, and experimental benchmarks. This valuable resource has laid a solid foundation for the development and validation of the work in this repository.
